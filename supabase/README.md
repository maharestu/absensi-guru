# 🗄️ Supabase Database Directory

Folder ini disiapkan untuk skrip SQL migrasi PostgreSQL, definisi skema basis data, triggers, dan konfigurasi RLS (Row Level Security).

- `schema.sql`: Berkas utama pembuat tabel `profiles`, `school_settings`, `attendances`, `leave_requests`, `rooms`, `subjects`, dan `schedules`.

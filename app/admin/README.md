# 🏫 Portal Admin Sekolah (Desktop Dashboard)

Folder ini disiapkan untuk antarmuka halaman admin sekolah (Desktop View) yang akan dikembangkan pada fase berikutnya.

Fitur utama yang akan diakomodasi di folder ini:
- `/admin/guru`: Kelola data & akun guru.
- `/admin/ruangan`: Kelola ruangan & cetak kartu QR Code.
- `/admin/jadwal-pelajaran`: Pemetaan Jadwal Mengajar Guru.
- `/admin/persetujuan`: Verifikasi pengajuan izin/sakit guru.
- `/admin/laporan`: Rekapitulasi & statistik kehadiran sekolah.

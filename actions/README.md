# ⚡ Server Actions Directory

Folder ini berisi fungsi **Next.js Server Actions** untuk pengolahan data backend (mutasi ke Supabase Database, Auth, dan Storage).

- `auth.ts`: Logika login, logout, & pendaftaran akun.
- `presensi.ts`: Logika mutasi presensi harian & mengajar.
- `izin.ts`: Logika pengajuan surat izin / sakit.
- `admin.ts`: Logika manajemen master data oleh Admin Sekolah.
